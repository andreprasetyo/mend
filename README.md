mend is one patch tool for every AI edit format - a single Node.js CLI (main.ts, standard library only) that applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON editor calls to a tree of files exactly as SPEC.md specifies, all-or-nothing, with three-tier line matching for drifted whitespace and indentation.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
